# Cfruit 水果營養成分計算機 & 商品法規標籤生成器 🍊

一個專為健康飲食、控糖、健身減脂、生鮮蔬果電商與食品包裝業者設計的水果營養計算與法規標籤產生 Web 應用程式。

收錄 34+ 種台灣在地常見與熱門進口水果，以**衛生福利部食品藥物管理署 (TFDA) 台灣食品營養成分資料庫**與**美國農業部 (USDA FoodData Central)** 標準數據為基準，並嚴格遵照食藥署**《包裝食品營養標示應遵行事項》**法規規範。

---

## ✨ 核心特色與功能

### 1. 💾 瀏覽器記憶功能 (Local Storage Persistence) - 全新支援！
- **即時自動儲存**：修改任何水果克重、品名、包裝份量或切換標籤樣式時，系統自動將設定儲存於瀏覽器本地（LocalStorage），**重新整理或關閉瀏覽器後重開，先前的搭配紀錄皆完整保留**。
- **自訂搭配管理 (My Recipes)**：
  - 點選 **「💾 儲存搭配」** 可將當前組合命名儲存（例如：「辦公室午後元氣盒 240g」、「高纖美顏早午餐」）。
  - 點選 **「📂 我的搭配」** 可隨時瀏覽、一鍵載入或刪除歷史已存配方。

### 2. 📊 完整匯出 Excel CSV 報表 (Export to CSV) - 全新支援！
- 點選 **「📊 匯出 CSV」** 可立即將當前水果搭配下載為標準試算表檔案。
- **內建 UTF-8 BOM 編碼**：保證在 Windows / Mac 的 Microsoft Excel 或 Apple Numbers 開啟絕不產生亂碼！
- **報表內容完整包含三大區塊**：
  1. 商品基本規格（品名、產出時間、搭配總重、每一份量、總份數、總淨重）。
  2. 搭配水果內容物清單（每款水果之公克數、熱量、三大營養素、飽和/反式脂肪、糖、纖維、鈉、維生素C、鉀、GI值與加總數值）。
  3. 衛福部 TFDA 商品法規營養標示雙欄與每日參考值百分比對照表。

### 3. 🥗 水果搭配計算 & 標籤總重即時自動同步
- 自由加入多種水果建立個人化搭配。
- 支援公克數輸入與滑桿（10g ~ 500g）。
- **右側標籤總重自動連動**：在左側調整水果公克數時，右側商品法規標籤的「每一份量」與「每份營養值」立即同步換算為整盒商品最新總重量！

### 4. 🏷️ 商品法規營養標示生成器 (TFDA Nutrition Label Generator)
- 完整產出台灣食藥署規範之**八大法定必標項目**（熱量、蛋白質、脂肪、飽和脂肪、反式脂肪、碳水化合物、糖、鈉）。
- 支援雙格式切換：
  - 格式一：每份 + 每 100 公克雙欄式（最通用市售格式）。
  - 格式二：每份 + 每日參考值百分比 (%)。
- 🖨️ **一鍵列印貼紙**：自動適配標籤印表機與貼紙尺寸，只列印標準黑白黑框標籤。
- 📋 **複製純文字**：便於貼入規格書或交件表。

## 🚀 快速啟動方式

本專案採現代化無相依性 (Zero-dependency) 架構設計，**無需執行 npm install，隨開即用**！

### 方法一：使用內建 Python 伺服器啟動（推薦）
在終端機中執行：
```bash
python3 server.py
```
程式會自動於本地開啟伺服器（預設 `http://localhost:3000`）並在預設瀏覽器中開啟頁面。

### 方法二：直接以瀏覽器開啟
直接在檔案總管中雙擊 `index.html`，或用 Chrome / Safari / Edge 開啟即可直接使用！

```

├── index.html              # 主網頁 (含 Tailwind CDN, 列印樣式與響應式排版)
├── server.py               # 本地輕量 HTTP 伺服器
├── package.json            # 專案資訊
├── README.md               # 專案說明文件
└── src/
    ├── app.js              # 核心前端邏輯 (記憶功能、CSV 匯出、搭配計算、法規標籤生成)
    ├── data/
    │   ├── fruits.json     # 完整水果營養素標準資料庫 (TFDA / USDA)
    │   └── fruitsData.js   # 支援獨立運行的全域資料模組
    ├── utils/
    │   └── nutritionCalculator.js  # 營養換算、DRI 與 TFDA 法規修約演算法
    └── components/         # React / 模組化元件備用檔
```
